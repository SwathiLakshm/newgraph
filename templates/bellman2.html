Bellman-Ford Problem 2

Problem Statement

A financial system models 6 currency exchange nodes (1–6) as a directed weighted graph. Using Bellman-Ford Algorithm, find the shortest-cost conversion path from Node 1 and detect any negative cycle.

Input Graph

Algorithm Used

Bellman-Ford Algorithm

Step-by-Step Execution

  1. Initialize dist[1]=0 and all others = ∞
  2. Perform 5 relaxation passes
  3. Update distances after each pass
  4. Perform 6th pass for cycle detection
  5. Negative cycle found
