Dijkstra Problem 2

Problem Statement

A computer network contains 6 routers (A–F) connected by links with non-negative latency values. Using Dijkstra's Algorithm determine the minimum-latency route from Router A to all other routers.

Input Graph

Algorithm Used

Dijkstra Algorithm

Step-by-Step Execution

  1. Initialize dist[A]=0
  2. Select A as source
  3. Visit nearest unvisited node
  4. Update neighboring distances
  5. Repeat until all routers are visited

Distance Table

Router Distance (ms)
A0
B7
C9
D20
E20
F11

Shortest Paths

A → B : A → B

A → C : A → C

A → D : A → C → D

A → E : A → C → F → E

A → F : A → C → F

Shortest Path Tree

A
├── B
└── C
    ├── D
    └── F
        └── E

Execution Time

0.001 ms

Complexity

Time Complexity : O((V+E) log V)
